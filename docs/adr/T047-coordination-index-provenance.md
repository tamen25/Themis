# T047: An operational index cannot authenticate history

Status: Accepted.

Version the coordination, proposal, approval, inventory, claim and action formats.
Validate digests, identities, approval windows, bounded strict JSON and canonical
relative evidence references. Public records contain no private capabilities.
The index projects the existing live report/inspection/verifier without another
verdict field or evaluator. Imported public claims grant no authority and cannot
become trusted PASS. Individually verified fixture signatures, unsigned client
timing and unauthenticated execution provenance stay separate. Later cleanup
cannot rewrite the historical result. Signing this index later would not prove
an entire historical experiment. There is no status publication/release gate.
