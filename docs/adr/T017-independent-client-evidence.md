# T017: Paired independent client evidence

Status: accepted for experimental T1.1 only.

Adapter success is a claim, not intervention evidence. Each fixed sample slot
collects concurrent direct, proxy and application client observations with a
fresh shared correlation ID. Signed fixture responses bind request identity,
endpoint kind and HTTP status to the public key in the approved plan. Data and
control credentials are distinct, and response-signing keys never travel over
HTTP. A replacement listener cannot forge evidence by echoing public IDs.

The observer requires a complete bounded baseline and at least three qualifying
paired latency increases. Full planned coverage, application assertions,
independent post-removal recovery and cleanup are required for PASS. Exact
rational threshold comparisons preserve v1alpha2 decimals. Credible signed
application failures remain visible with other inconclusive checks.

CPU scheduling and loopback contention can confound latency; the predicate is
empirical support under these conditions, not causal certainty. The observer and
fixture share a machine. Signatures authenticate response messages, not honest
software, client clocks or whole journals. Same-user journal forgery remains
possible and is explicitly outside replay's consistency claim.
