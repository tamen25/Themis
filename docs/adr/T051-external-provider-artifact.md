# T051: A new provider does not inherit synthetic authorization

Status: Accepted for non-executable planning.

Use a separate versioned Chaos Mesh plan and admission envelope. Bind independently
resolved environment/request/preview/workload/Pod/container/image, provider source
and image pins, exact candidate resource/parameters, invocation, proposed approver
and required deadlines. The public plan grants no authority and the resource UID
is explicitly unbound. Deny old synthetic grants and caller-supplied capability
flags. No existing plan, approval, journal, evaluator or coordination format changes.
Actual external authorization and cleanup authority remain unimplemented.
