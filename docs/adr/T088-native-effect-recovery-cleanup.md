# T088: Separate observed effect, application outcome and original cleanup

A separate read-only observer measures real direct, proxy and application HTTP
requests. Check fresh nonces, exact signed nested identities, chain/order and own
elapsed times. Require independent application effect beyond a proxy hold or
acknowledgement. PASS also needs adequate baseline/recovery, application assertions,
current immutable identity and confirmed original inactive/fenced cleanup.

No-effect and missing evidence remain INCONCLUSIVE. Credible violation stays FAIL;
cleanup uncertainty stays separately visible. A proxy crash or replacement cannot
prove application recovery. Later inventory-based reconciliation writes a new
receipt without modifying original history. Offline predicates never create a
trusted PASS; T4.2 collection clocks and whole execution remain unauthenticated.
