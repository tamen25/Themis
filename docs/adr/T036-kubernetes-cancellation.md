# T036: Cross-process cancellation of an inventoried invocation

Status: Implemented for T2.2 owned Kind; independent review required.

Protected v1alpha2 inventory binds full approved plan, exact authorization and
absolute setup path. Verify signature, key pairs and bindings before accepting
an action. Fresh authenticated environment/Pod/boot checks precede control.
The original runner need not exist. Never kill a PID or resolve another target.

Persist intent and canonical stop before Remove. The stop fences participating
runners; authenticated Remove fences first Apply in the fixture. Unreachable
control cannot prove that remote fence: retain CLEANUP_PENDING, local stop and
independent expiry. Repeat actions record immutable receipts without renewal.
Live legacy runners lack the protocol and are refused. Private file mechanics
are reused; Kubernetes grants/identity continue to authorize every action.
