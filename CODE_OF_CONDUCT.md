# Code of conduct

Treat participants with respect. Critique ideas and code constructively. Welcome
questions and differing experience levels. Harassment, threats, discriminatory
behavior and disclosure of another person's private information are unacceptable.

Maintainers may remove harmful contributions or restrict participation, and
should explain their decisions without exposing private reports. Report conduct
concerns privately to a repository maintainer using a contact channel listed on
their GitHub profile. Do not publish another participant's private details.
